# MED-TSO SMS v6.3.1 — Executive Gap Visualisation

Adds an attractive executive gap dashboard inside **KPIs**:

- Executive metric cards
- Ranked task-coverage chart by Technical Committee
- Committee → Task → Missing TSO drill-down
- Risk bands: High Risk (<50%), Watch (50–74.9%), Healthy (≥75%)
- Committee filter
- Responsive layout for sidebar and browser views
- Gap Analysis sheet refresh remains available

## Deployment

1. Copy the release files into the clasp project.
2. Run `clasp push`.
3. Reload the spreadsheet and open the Management App.
4. Open **KPIs**; the visualisation loads automatically.

No spreadsheet migration is required beyond the existing v6.3 setup.
