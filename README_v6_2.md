# MED-TSO SMS v6.2 — Member Search Enhancement

## Changes
- Member Search cards now show Primary Phone.
- Member Search cards now show active Technical Committees.
- Member Search cards now show active Assigned Tasks.
- Member form now supports Primary Phone.
- The `Primary Phone` column is created automatically in the Members sheet when the app first loads.

## Deploy
```bash
clasp push --force
```
Then refresh the Google Sheet with Command + Shift + R and reopen the Management App.
